# :snake: How Beginners Should Use Grok (or Any AI Assistant)

The best way for a beginner to use Grok (or any AI) is to treat it as a **patient tutor**, not as a code-writing machine.

---

## :brain: Core Mindset

AI works best when it helps **you** think — not when it does the thinking for you.

---

## :white_check_mark: Best Practices

### 1. Always try first
Write as much as you can on your own before asking for help.  
Even a messy or incomplete attempt is valuable. When you then ask the AI, you learn much more because you already have a mental model of the problem.

### 2. Ask for explanations, not just finished code
Instead of saying:

> “Write a rock-paper-scissors game”

Try:

> “I want to make a rock-paper-scissors game. Can you explain the main steps I need, and then show me a simple version with comments so I understand each part?”

Or even better:

> “Here’s what I have so far… It’s not working. Can you explain what is wrong and help me fix it step by step?”

### 3. Request step-by-step breakdowns
Good prompts include:

- “Explain this like I’m new to programming.”
- “Walk me through this code line by line.”
- “What does this error message mean, and how can I fix it?”
- “Show me the same idea in a simpler way first.”

### 4. Use the AI to check your understanding
After you think you understand something, test yourself:

> “I just learned about `if` / `elif` / `else`. Can you give me three short practice problems (without answers) so I can try them?”

Then come back and ask it to check your solutions.

### 5. Never copy code you don’t understand
If the AI gives you a working program, ask:

- “Can you add comments that explain every important line?”
- “Why did you use a list here instead of separate variables?”
- “What would happen if I changed this part?”

Understanding is more important than a working program.

### 6. Learn to read error messages with the AI
When you get a red error, paste the full error and your code, then ask:

> “Please explain what this error means in plain English and how I can fix it.”

This builds a very useful skill over time.

### 7. Keep conversations focused
One concept or one small program at a time works best.  
Long, vague requests usually produce answers that are harder for beginners to learn from.

---

## :star: Simple Rule of Thumb

> If the AI does the thinking for you, you learn very little.  
> If the AI helps *you* think more clearly, you learn a lot.

---

## :speech_balloon: Quick Prompt Starters

| Goal                        | Example Prompt |
|----------------------------|----------------|
| Understand a concept       | “Explain lists like I’m brand new to Python.” |
| Get unstuck                | “Here’s my code and the error. What’s wrong?” |
| Practice                   | “Give me 3 small practice problems on loops.” |
| Improve code               | “How can I make this clearer for a beginner?” |
| Check understanding        | “Quiz me on `if` statements.” |

---

**Remember:** The goal is not just working code — the goal is becoming a stronger programmer.
