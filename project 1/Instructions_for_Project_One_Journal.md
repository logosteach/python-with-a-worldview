# Instructions for the Project One Journal

This journal is a learning tool, not busywork. Use it to notice what you’re understanding, what is still unclear, and how you are growing as you build the Gator Invader project.

## High-Value Prompts
Pick two or three of these for each lesson entry. Answer them honestly and briefly.

- What did you expect to happen versus what actually happened?
- Where did you get stuck, and how did you get unstuck?
- What part of the code are you proud of, and why?
- What would you explain differently if you were teaching this to a friend?
- What small improvement would you make if you had 15 more minutes?
- How does this piece of the game (movement, collision, sprites, etc.) connect to something you already know?

## Optional Worldview / Integration Prompts
These are invitational. Include one when it feels natural.

- What does it look like to work with excellence and honesty on this project?
- Where did you practice patience or carefulness today?
- How might the idea of “order” or “stewardship” show up in how we organize code?

## Light Scaffolding Tips
- Short entries are better than long ones. Five to ten sentences is plenty.
- You may include a short code snippet or a brief description of a screenshot if it helps you remember.
- A simple “before / after” note is powerful (“Before this lesson I didn’t know how to… Now I can…”).
- At the end of the project, write one short reflection: “Looking back at the whole project, what is one skill or habit that grew?”

Write for your future self. The goal is clarity and growth, not perfection.
